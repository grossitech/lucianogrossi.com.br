# CLAUDE.md — lucianogrossi.com.br

Site estático (HTML, CSS e JS puros) publicado pelo GitHub Pages a cada push na `main`.

- **Antes de criar ou alterar qualquer página, leia o [DESIGN.md](DESIGN.md).**
- **Toda mudança visual (cor, fonte, espaçamento, componente, página nova com padrão novo) atualiza o `DESIGN.md` no mesmo commit.** Se resolver uma das "Pendências conhecidas", tire-a da lista.
- Página nova: siga o checklist do `DESIGN.md` (card na home, `README.md`, `sitemap.xml`).
- Ao mudar `style.css`, `guia.css`, `osint/catalogo.css` ou `osint/catalogo.js`, aumente o `?v=` nos links de todas as páginas que os usam.
- Material de cursos não é publicado; guias são escritos do zero.
